## 🧠 How I Build & Learn

I use a project-based approach: understand the problem, break it into manageable tasks, build an implementation, test it, debug issues, and improve it over time.

I also use AI-assisted development tools, including Antigravity and DeepSeek, as part of my workflow. I guide the tools, review and integrate generated code, test behaviour, debug issues, and use the process to learn.
